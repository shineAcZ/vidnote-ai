生成策略 默认关闭：整份字幕一次生成，速度快且结构更连贯。开启后会分块并发整理并执行最终合并，适合超出模型上下文的长视频。

AI 设置

密钥仅保存在本机扩展存储中，不会写入日志。

DeepSeek 思考模式 开启后通常更适合长字幕整理，但会增加等待时间和 Token 消耗。生成时仅显示“AI 正在思考”，不会展示内部推理文本。
高级设置
DeepSeek V4 最大输出为 384K。默认使用 384,000；模型自然完成时会提前停止，不会因为上限较大而强制生成到上限。 默认 30,000 字符，减少过小分块，同时让长视频仍可并发处理；可提高到 800,000。输入与输出共同占用 1M 上下文，使用极大字幕块时应适当降低最大输出。 可设置 1–2500，默认 8。DeepSeek Flash 账号上限 2500、Pro 上限 500；实际请求数不会超过剩余字幕块。遇到 429/503 会自动降低并发并重试。同一账号的所有 API Key 共用额度，高并发也会增加本机占用和瞬时 Token 消耗。
字幕行为 关闭后仍会显示已经保存的字幕，新视频需要在“完整字幕”中手动点击“读取”。
外观 切换后立即生效，并保存在本机。
发送范围

生成笔记时，视频标题和字幕会发送给你选择的 AI 服务。不会发送网页 Cookie 或账号信息。
